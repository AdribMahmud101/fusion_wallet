## Chart kit (new `ui/charts/`; Compose Canvas; no chart library unless already a dependency)
- `DonutChart(segments: List<Segment(label, valueRaw, color)>, centerTop, centerBottom)` — rounded caps, 2 dp gaps, animated sweep on first show (respect system animator scale / reduce-motion), legend rows "● Label  NN %" (text, not color alone), contentDescription summarising all segments.
- `RadialGauge(value, max, centerValue, centerUnit, status, tone)` — 270° arc track + progress, status line in text ("Healthy", "Keep an eye on it", "Low").
- `AreaLineChart(points, …)` — monotone cubic interpolation (no overshoot), gradient fill, real points as small markers, glowing end dot, value + ▲/▼ % header, x-range caption; ≥ 4 points else stat-tile fallback.
- `WeeklyBars(weeks: List<WeekBucket(label, segments)>)` — rounded columns, stacked by category, empty week shows a flat placeholder bar, legend with totals.
- `ProgressBars(rows: List<(label, valueText, fraction, tone, note?)>)`.
JVM tests for all math: segment percentages (sum 100, rounding), gauge clamp, monotone cubic no-overshoot, weekly bucketing by local week, runway calculation.
