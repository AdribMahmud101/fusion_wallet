# fusion_wallet Helper & AI Context Workspace

This directory is monitored and actively leveraged by autonomous AI coding agents and the orchestrator supervisor to guide planning, architecture synthesis, code generation, and test execution.

## Default Organization:
- `specs/`: System requirements, PRDs, architecture specifications, API references, PDF/DOCX specs.
- `schemas/`: Database schemas, Prisma models, OpenAPI definitions, JSON schemas, TypeScript types.
- `prompts/`: Domain-specific prompts, coding style guidelines, operational rules, instructions for AI agents.
- `notes/`: Meeting notes, developer decisions, scratchpad, project roadmaps.

## Creating Custom Folders:
You can create additional folders and drop relevant files here anytime (or anywhere in the project tree). The AI supervisor automatically discovers and indexes files inside this workspace.
